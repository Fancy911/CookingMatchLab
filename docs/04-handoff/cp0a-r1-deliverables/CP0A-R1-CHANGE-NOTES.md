# CP0-A-R1 修改说明

## 调整节点

- 顶部：`PauseButton`、`StepBadge`、`StepValue`、`LabTitle`。
- 订单托盘：`OrderTray`、`OrderDish`、`OrderTitle`、两组食材图标与需求范围。
- 棋盘：`BoardFrame`、49 个 `Slot_*` 与对应 `Ingredient_*`。
- 锅与投料：`PotTomato`、`PotEgg`、`PotLamp1/2`、`ThrowTray`、三个投料槽内容、`FireButton`、`FireReady`。
- 料理揭晓：普通徽章、料理、揭晓台、名牌、三星、原因文字、图鉴按钮和继续按钮。

## 对齐基准

- 顶部标题、棋盘框、7×7 矩阵和揭晓主体统一使用屏幕中心线 `x=195`。
- 暂停按钮与步数徽章分别使用独立左右安全边距，不参与标题居中计算。
- 订单托盘使用固定四列栅格：菜品缩略图、菜名、番茄需求、鸡蛋需求；图标和文字共用 `y=132` 视觉中心。
- 棋盘使用程序化布局：槽位尺寸 70、行列步进 49、整体宽度 364，由屏幕宽度自动计算左边距；未修改 49 格固定内容。
- 锅内番茄和鸡蛋分别对齐到两个处理位；两颗处理星与对应投料位使用相同中心线。
- 三个投料槽使用统一的左起点数组、图标高度和注释基线；投料托盘与开火按钮按透明资产可见边界的垂直中心对齐。
- 揭晓料理、揭晓台、名牌、三星组均以 `x=195` 居中；底部两个按钮高度和 `y` 坐标相同，保持主次宽度差异并统一可见底边。

## 料理成品素材

- 已修改订单托盘使用的番茄炒蛋缩略图：通过 Codex 内置 `imagegen` 精确编辑，移除全部葱花、香葱碎及绿色装饰，仅保留番茄和鸡蛋。
- 揭晓大图原本已只包含番茄和鸡蛋，因此未重绘。
- 图片生成源图：`docs/04-handoff/cp0a-r1-sources/dish-thumbnail-no-scallion-source.png`。
- 最终运行资产：`assets/resources/game/art/ui/battle/dish_thumbnail.png`（400×400 RGBA）。
- 最终提示词核心约束：仅移除所有绿色葱花/香草并以匹配的金黄色炒蛋纹理补齐；保持碗、番茄、鸡蛋、构图、光照、G1-B 果冻玩具材质和洋红抠图背景不变；不得出现第三种食材、文字或水印。
